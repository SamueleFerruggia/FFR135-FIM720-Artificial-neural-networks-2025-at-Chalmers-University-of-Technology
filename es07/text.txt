Here is a self contained program to help you debug csv errors, to be run under python3.  (actually python3.11, but other versions should be ok. ) Place your player1.csv and your player2.csv file in the same directory as the python code. Then run the python. If you get no errors, the file is probably ok. If you get errors, your csv files will not work on OpenTA tic-tac-toe problem. 

Full instructions for linux.  


python3 -m venv env

source env/bin/activate

import csv
import numpy as np
def read_csv(playercsv):
    print(f"READING {playercsv}")
    Q_matrix_file=open(playercsv)
    Q_matrix=list(csv.reader(Q_matrix_file))
    Q_matrix=np.array(Q_matrix)
    Q_matrix=Q_matrix.astype(float)
    Q_matrix_file.close()

    if Q_matrix.shape[0] != 6 or Q_matrix.shape[1]%3 != 0:
        raise TypeError("Shape of ", playercsv, " is wrong.")

    boards_tobechunked, actions_tobechunked = np.split(Q_matrix, 2, 0)

    num_of_boards = int(boards_tobechunked.shape[1]/3)
    Boards = np.split( boards_tobechunked, num_of_boards, 1)
    Actions = np.split( actions_tobechunked, num_of_boards, 1)
    player = [Boards, Actions]

    return player

student_player1 = read_csv( './player1.csv')
